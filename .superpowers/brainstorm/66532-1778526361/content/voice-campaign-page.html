Voice Campaign — Page Layout Options

Where does this live and how is it structured?

A

Under /campaigns (channel tab)

Campaigns page gets two tabs: Email | Voice. Voice tab has a "New Voice Campaign" button → opens a full creation page. Sits alongside existing email campaign list.

Pros

  • Reuses existing campaigns nav
  • All outreach in one place

Cons

  • Email campaigns are segment-specific today
B

From segment detail page

On any segment's detail page, a "Launch Voice Campaign" button opens a full-page flow (or modal). The segment is pre-selected — user only defines the offer + numbers + launches.

Pros

  • Natural fit — segment first, action second
  • Segment context auto-injected into script

Cons

  • Campaign list lives under segment (siloed)
C

Standalone /voice-campaigns page

New sidebar nav item. Top-level page: list of voice campaigns + "New Campaign" button. Creation flow has a segment picker as step 1.

Pros

  • Full campaign list + history visible
  • Can create without starting from segment

Cons

  • Adds a nav item
